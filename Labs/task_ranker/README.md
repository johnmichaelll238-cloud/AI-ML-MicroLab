## Task Ranker Lab

### Goal
Sort tasks by priority and return structured output

### What I built
A simple ranking function using Python sorted()

### What I learned
-Sorting with key function
-Seperation of data, logic and execution
-Basic idea of scoring systems

### Insight
A priority system is a primitive model, more parameters should be included, like urgency and "importance".
I've added weighted scoring to the prioritisation process. It doesn't fully capture the true essence of human decision, but it is less primitve than a single number representing the importance of a person's decision.
