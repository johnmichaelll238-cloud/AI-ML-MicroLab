## Anomaly Detection Matrix Lab

### To detect anomalous data values in a matrix made up of data of some kind, for example records of frequency of requests sent to a server.

### What I built
A simple algorithm used to find outliers in a data set. Used NumPy for creating random data values and matrix formation

###
-Basic usage of the NumPy module
-Several techniques or methods for determining what an "outlier" value really is

### Insight
The better your statistical method of determining outliers and anomalies, the less likely false positives and errors are.
You could hardcode the threshold for "normalcy", you could use a statistical mean and find the average value in the dataset, you could calculate the Z-score(number of standard deviations from the mean). Accuracy increases the more thorough your approximation is.
